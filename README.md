# DSA Practice

Source: https://risingbrain.org/sheet/pattern-wise-sheet

## Layout

```
dsa/
  README.md
  PROGRESS.md
  <nn>-<topic>/
    <pattern>/
      <problem-slug>.js
```

One file per problem, stubbed when we reach its pattern. Each file holds the problem statement, examples, the solution, and its time/space complexity.

## Workflow

1. Pick the next unchecked problem in PROGRESS.md.
2. State the approach and complexity before coding.
3. Solve in the problem's file, then review.
4. Tick it in PROGRESS.md. Mark `R` if it needs a re-solve in a few days.
